API 1: World Bank EdStats مجاني، بدون مفتاح API، مفتوح 100%

واجهة البنك الدولي لمؤشرات التعليم بالمغرب (World Bank API)

Endpoint: http://api.worldbank.org/v2/

توفر هذه الواجهة سلاسل زمنية كاملة من سنة 1970 إلى 2024 لكل مؤشرات التعليم بالمغرب. يمكنك استدعاؤها عبر أي لغة برمجة بصيغة JSON أو XML أو CSV.

GET http://api.worldbank.org/v2/country/MAR/indicator/SE.SEC.ENRR?format=json&date=1980:2024&per_page=1000
كود بايثون لسحب البيانات الخام وتخزينها فـ Dataframe : 
# سحب بيانات التمدرس بالثانوي والتأطير بالمغرب عبر البنك الدولي
import requests
import pandas as pd

indicator = "SE.SEC.ENRR"  # نسبة التمدرس بالثانوي
url = f"http://api.worldbank.org/v2/country/MAR/indicator/{indicator}?format=json&date=1990:2024&per_page=1000"

resp = requests.get(url).json()
records = [{"year": r["date"], "value": r["value"]} for r in resp[1] if r["value"] is not None]
df = pd.DataFrame(records)
print(df.head(10))
أهم رموز المؤشرات المتاحة للمغرب (Indicator Codes) :
SE.SEC.ENRR: تمدرس الثانوي التأهيلي (%)
SE.PRM.ENRR: تمدرس الابتدائي (%)
SE.TER.ENRR: تمدرس التعليم العالي (%)
SE.PRM.CMPT.ZS: نسبة إتمام الابتدائي (%)
SE.XPD.TOTL.GD.ZS: ميزانية التعليم (% من GDP)
SE.PRM.ENRL.TC.ZS: معدل التأطير (تلميذ/أستاذ)
API 2: data.gov.ma (CKAN Engine) البوابة الوطنية للبيانات المفتوحة للمملكة المغربية

واجهة برمجة بوابة البيانات الوطنية (CKAN Action API)

Endpoint: https://data.gov.ma/data/api/3/action/

يعتمد المغرب على محرك CKAN المعياري دولياً. تتيح لك الواجهة الاستعلام البرمجي وجلب روابط التحميل المباشرة لقواعد بيانات المدارس العمومية، المدارس الخصوصية، الخرائط المدرسية والمؤشرات الاجتماعية بصيغ CSV و XLS.

GET https://data.gov.ma/data/api/3/action/package_search?q=education&rows=50
كود سحب وتحميل ملفات المؤسسات التعليمية من data.gov.ma برمجياً : 
# استعلام CKAN API وجلب روابط ملفات إكسيل لمدارس المغرب
import requests

api_url = "https://data.gov.ma/data/api/3/action/package_search?q=education"
response = requests.get(api_url).json()

for dataset in response["result"]["results"]:
    print("Dataset:", dataset["title"])
    for resource in dataset.get("resources", []):
        print(f"  -> Format: {resource['format']} | URL: {resource['url']}")
Raw Microdata 3: OECD PISA قاعدة البيانات الدقيقة للتلاميذ (Microdata)

قاعدة البيانات الخام لتقييم PISA (بيانات التلاميذ الفردية لـ 6,867 تلميذاً مغربياً)

oecd.org/pisa-2022-database ↗

منظمة OECD لا توفر REST API للميكروداتا لأن الملفات ضخمة (ملايين الإجابات)، بل تتيح الميكروداتا الخام كاملة للتحميل بصيغ SPSS (.sav) و SAS و CSV ومستودع Zenodo المفتوح (DOI: 10.5281/zenodo.13382904).

الملفات الخام التي تتضمن بيانات المغرب (ISO: MAR) :
  • • CY08MSP_STU_QQQ.sav : استبيان التلاميذ + درجات الكفايات (PV1MATH..PV10MATH, PV1SCIE, PV1READ) لـ 6,867 تلميذاً مغربياً مع الوضع السوسيو-اقتصادي (ESCS).
  • • CY08MSP_SCH_QQQ.sav : استبيان مديري المؤسسات المغربية الـ 180 المشاركة (تجهيزات المؤسسة، الغياب، التأطير).
  • • CY08MSP_TCH_QQQ.sav : استبيان الأساتذة والتكوين البيداغوجي.
كيفية استخراج عينة المغرب من ملف PISA الخام بـ Python (مكتبة pyreadstat) : 
# قراءة ملف SPSS العالمي واستخراج سطور المغرب فقط (CNT == 'MAR')
import pyreadstat

df, meta = pyreadstat.read_sav("CY08MSP_STU_QQQ.sav", usecols=["CNT", "STRATUM", "PV1MATH", "PV1SCIE", "PV1READ", "ESCS", "ST004D01T"])
morocco_students = df[df["CNT"] == "MAR"]
print(f"Total Moroccan Pupils: {len(morocco_students)}")
morocco_students.to_csv("Morocco_PISA_2022_Pupils_Raw.csv", index=False)
Raw Microdata 4: IEA TIMSS & PIRLS مستودع بيانات بوسطن كوليدج و IEA

المستودع الدولي لاختبارات TIMSS و PIRLS للمغرب

timssandpirls.bc.edu ↗

توفر الرابطة الدولية لتقييم التحصيل التربوي (IEA) ملفات الميكروداتا الخاصة بالمغرب (MAR) بصيغة SPSS جاهزة مع حزمة برمجيات IDB Analyzer للتحليل الإحصائي الموزون.

الملفات المباشرة لتلاميذ المغرب :
  • • ASGMARM7.SAV : معطيات الصف الرابع ابتدائي (4AEP) بالمغرب (رياضيات وعلوم وخلفية التلميذ).
  • • BSGMARM7.SAV : معطيات الصف الثاني إعدادي (2AC) بالمغرب (الفيزياء، الكيمياء، علوم الحياة والأرض، والرياضيات).
  • • ACGMARM7.SAV / BCGMARM7.SAV : بيانات المؤسسات والمديرين.
